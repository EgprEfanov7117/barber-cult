# BARBER CULT — портфолио AI-студии NOVARY

**Публичный сайт:** [egprefanov7117.github.io/barber-cult](https://egprefanov7117.github.io/barber-cult/)

**Репозиторий:** [EgprEfanov7117/barber-cult](https://github.com/EgprEfanov7117/barber-cult)

BARBER CULT — демонстрационный лендинг вымышленного премиального барбершопа. Проект показывает подход AI-студии NOVARY к дизайну и разработке коммерческих сайтов: выразительную типографику, адаптивную композицию, внимание к деталям и доступность интерфейса. Визуальное направление — Premium Editorial Minimalism.

## Технологии

- HTML5: семантические разделы, доступные названия элементов и нативный dialog.
- CSS3: Grid, Flexbox, адаптивная вёрстка, состояния фокуса и prefers-reduced-motion.
- Vanilla JavaScript: меню, навигация, демодиалоги и переключение примеров отзывов.
- Локальные изображения WebP/JPEG и шрифты WOFF/TTF с лицензиями.
- GitHub Pages: статическое размещение в подкаталоге `/barber-cult/`.

Сборка, npm и сторонние JS-библиотеки не нужны. Внешние API, аналитика, cookies и сбор персональных данных отсутствуют.

## Демонстрационный характер

Бренд, история и мастера вымышлены. Цены, график, контакты и отзывы приведены как примеры. Фотографии служат визуальными референсами, не являются работами BARBER CULT и не изображают сотрудников бренда. Источники: [credits.html](credits.html) и [CREDITS.md](CREDITS.md).

Кнопки записи открывают пояснение о деморежиме; настоящая запись не ведётся. Email `hello@barbercult.example` не принимает письма. Кнопки соцсетей не перенаправляют на чужие аккаунты. Проект можно показывать как концепт NOVARY; его нельзя представлять как сайт действующего барбершопа или подтверждённый клиентский кейс.

## Локальный запуск

Из корня скачанного или клонированного репозитория:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть http://localhost:8080. Остановить сервер: Ctrl+C. Также можно просто открыть index.html в браузере.

## Структура

- index.html — семантическая разметка и все разделы лендинга.
- styles.css — дизайн, адаптивность, анимации и reduced-motion.
- script.js — мобильное меню, демодиалоги, переключение отзывов, появления блоков.
- assets/images/ — пять локальных фотографий и облегчённая версия первого экрана, WebP с JPEG-fallback.
- assets/fonts/ — локальные шрифты WOFF/TTF и их лицензии.
- assets/favicon.svg и favicon.ico — иконки BC.
- CREDITS.md — авторы и источники изображений.
- credits.html — страница источников для посетителей.
- QA_REPORT.md — результаты комплексного аудита.
- PORTFOLIO_CHECK.md — финальная проверка GitHub Pages и подготовка для портфолио.

## Поведение

Навигация прокручивает страницу к разделам. Мобильное меню закрывается после выбора раздела, по Escape, при клике снаружи и при переходе на desktop. Запись открывает нативный dialog с выбранной услугой или мастером и явным предупреждением о деморежиме. Диалог закрывается кнопкой, по Escape и кликом по фону; фокус возвращается к вызвавшей его кнопке. Ссылки соцсетей показывают пояснение вместо перехода на чужой аккаунт. Отзывы переключаются вручную без автопрокрутки и отмечены как примеры.

При отключённом или заблокированном JavaScript содержимое и навигация остаются доступными, а интерактивные кнопки отключены. Для пользователей, предпочитающих уменьшенное движение, плавная прокрутка и анимации отключены. Поддерживаются актуальные браузеры с HTML dialog, CSS Grid, IntersectionObserver и matchMedia.
