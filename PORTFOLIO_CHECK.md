## Фактически выполненные проверки

### HTTP и пути

Проверены 25 публичных URL: главная страница, index.html, credits.html, CSS, JavaScript, favicon, все варианты фотографий, оба формата шрифтов и лицензии. Все ответы — HTTP 200. Проверены MIME-типы: text/css, application/javascript, image/jpeg, image/webp, font/woff и font/ttf.

Байты проверенных опубликованных статических ресурсов совпадают с локальными файлами по SHA-256. HTML сравнивать на идентичность не требовалось: локально изменены метатеги, которые ещё не отправлены.

Все внутренние href, src, srcset и url() CSS разрешаются внутри `/barber-cult/`. Проверены относительные пути с обеих страниц, отсутствие localhost/file:// в ресурсах сайта, уникальные ID и существование целей якорей. Тег base не используется; он не вмешивается в навигацию по секциям.

### Опубликованный сайт в Chrome

- Сайт открыт по публичному HTTPS-адресу. Первый экран просмотрен визуально.
- JavaScript инициализировался: кнопки активны, присутствует класс has-js.
- Все восемь размещений изображений загрузились в браузере; document.fonts.status — loaded, заголовок использует Oswald.
- Проверены пять пунктов основной навигации с Enter: URL-хеш и фокус соответствуют целевым разделам.
- Проверены выбор мужской стрижки, текст деморежима и закрытие диалога по Escape.
- Проверено переключение примера отзыва вперёд и обратно.
- Проверено пояснение для демоссылки VK.
- На ширине 390 px меню открывается и закрывается после выбора раздела; viewport и scrollWidth равны 390 px.
- На исходной desktop-ширине 1470 px viewport и scrollWidth совпадают.
- Переход на страницу источников выполнен, её заголовок и содержимое доступны.
- В проверенных сценариях до перехода на страницу источников консоль Chrome не содержала ошибок и предупреждений.

При попытке автоматической проверки возврата со страницы источников браузерный инструмент перестал отвечать. Этот последний сценарий не засчитан как завершённый и оставлен для ручной проверки. Тайм-аут инструмента сам по себе не доказывает ошибку сайта. Его HTML-ссылка и HTTP-ответ целевой страницы проверены отдельно.

### Локальная версия

Проверены canonical, og:url и абсолютные HTTPS-адреса изображений в обеих HTML-страницах. Заявленные размеры OG-изображения совпадают с реальным файлом. Twitter Card использует то же изображение. `node --check script.js` и `git diff --check` завершились успешно.

Локальную версию с новыми метатегами не запускали в отдельном браузерном сервере. Вёрстка и скрипт не менялись; метатеги проверены разбором HTML и HTTP-доступностью используемых публичных ресурсов.
